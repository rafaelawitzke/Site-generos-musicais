## Sobre o projeto

O site Universo dos Gêneros Musicais apresenta diferentes estilos musicais, suas características, artistas e exemplos de álbuns. O objetivo é reunir informações sobre gêneros musicais em cinco páginas organizadas em HTML.

## Como abrir o projeto

1. Baixar os arquivos do repositório.
2. Extrair a pasta do projeto.
3. Abrir a pasta no Visual Studio Code.
4. Abrir o arquivo index.html no navegador.

## Páginas

- index.html: apresentação dos gêneros musicais.
- sobre.html: história e características dos estilos.
- dados.html: tabela com gêneros e artistas.
- cadastro.html: formulário de preferências musicais.
- contato.html: informações e formulário de contato.
